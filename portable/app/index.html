Security controls are active before the first connection

The package is portable and contains no installer. It does not disable antivirus, endpoint protection, RBAC, database permissions, or company policy.

Loopback binding Per-launch API token Content Security Policy Command allowlists Bounded input and output No saved passwords
◆

Loopback only

The service binds to 127.0.0.1. Other machines cannot connect to it.

◉

Same-origin token

API requests require a random token created for the current launch.

▤

Read-only first

Mutating SQL is rejected until write mode is explicitly enabled.

⌁

No credential files

Passwords remain in memory and are not saved by DBridge.

≡

Bounded file reads

Log tails and trace analysis enforce size limits and never modify files.

◫

No auto-installs

DevOps actions use tools already approved and available in PATH.

!
Company policy still applies

Use only approved credentials, database accounts, log paths and platform contexts. DBridge does not bypass endpoint security or access controls.
