DBridge Portable v2.30 - Security Notes
=======================================

Purpose
-------
This package is a local database and DevOps diagnostic console. Extract it to
a user-writable folder. On Windows use Start-DBridge.cmd; on macOS or Linux use
node portable-launcher.mjs or sh start-dbridge.sh. Close the terminal window or
press Ctrl+C to stop DBridge.

Security boundary
-----------------
- The local service binds only to 127.0.0.1.
- Non-local Host headers are rejected.
- Every launch creates a new random API token.
- Browser responses use a restrictive Content Security Policy, frame blocking,
  MIME sniffing protection, no-referrer policy, same-origin resource controls,
  and restricted browser feature permissions.
- SQL and infrastructure workflows start read-only.
- Write actions use fixed allowlists, explicit unlocking, preflight checks and
  user confirmation.
- Passwords are not written to DBridge configuration or session files.
- Log and trace reads are bounded and never modify the source file.
- Runtime trace capture uses fixed retained-evidence checks. Profiler, tracing,
  optimizer trace, Extended Events and server settings are never enabled.
- Session-changing trace examples are emitted only as commented, review-only
  terminal templates and are never submitted to a database.
- Arbitrary shell text is not accepted by the DevOps GUI or Terminal workspace.
- Terminal tabs restore only non-secret profile context; their output is session-only.
- The Windows offline bundle does not download tools. The Node-portable bundle runs locked npm dependency installation only when node_modules is absent.

Company controls
----------------
DBridge does not disable or bypass antivirus, endpoint detection, application
allowlisting, email filtering, proxy controls, database permissions, SSH
permissions, Kubernetes RBAC, Docker daemon permissions, or company policy.
Your security team may still block portable runtimes, command files, database
drivers, or unsigned internal applications. Obtain approval when required.

Package verification
--------------------
The release folder includes:

1. DBridge-Portable.zip and its SHA256 file (Windows offline)
2. DBridge-Node-Portable.zip and its SHA256 file (all Node.js platforms)
3. DBridge-Node-Portable.tar.gz and its SHA256 file (macOS/Linux friendly)

Use the SHA256 value to confirm that the received ZIP matches the original.
The ZIP also contains PACKAGE-MANIFEST.txt with hashes of its application files.

Sharing
-------
Send the ZIP only through a company-approved email or file-transfer channel.
Do not include database passwords, SSH keys, cloud tokens, connection exports,
logs, traces, or incident evidence in the package.

- Interactive SSH server tabs inspect a new host key before authentication, ask for
  approval once, pin the fingerprint locally, and block unexpected key changes. Hostname, IPv4, and IPv6 inputs are
  validated. Sessions are bounded and expire after inactivity.
- Saved server profiles contain only label, host, port, username, and selected
  authentication method. Passwords and passphrases can be kept only in the running agent's bounded,
  expiring memory vault; they are never written to browser storage.
